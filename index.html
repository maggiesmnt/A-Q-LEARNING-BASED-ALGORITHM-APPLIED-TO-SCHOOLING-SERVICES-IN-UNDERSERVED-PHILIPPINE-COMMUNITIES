Road & hazard status

This is the answer to “how do we know a path is unavailable?” Every road segment carries an accessibility coefficient A — the fifth term of the state vector S = ⟨L, D, T, H, A⟩. A is not typed in by hand: it is fused from four independent signals, each of which decays over time unless it is re-confirmed.

How A is computed

A = baseline surface score × weather factor × report factor, clamped to [0, 1]. The band A falls into decides whether the segment stays in the agent’s action set at all.
SignalWhere it comes fromEffect on A
Surface baselineOpenStreetMap road class — concrete provincial road, gravel barangay road, unimproved mountain path, river crossingSets the ceiling: 1.00 / 0.85 / 0.65 / 0.50
Weather telemetryRainfall & seasonal pattern feed (Dynamic Weather and Road Accessibility Telemetry dataset)Scales unpaved segments hardest: ×1.00 dry, ×0.85 light, ×0.60 heavy, ×0.35 extreme
Field / community reportDriver or barangay tap on the REPORT button: landslide, flooding, washout, fallen tree, impassablePulls A toward the severity floor, weighted by confidence
Official advisoryLGU / DPWH / MDRRMO closure noticeHard override: A = 0 until lifted
Unit telemetryMobile unit turns back or stalls on a segment mid-routeAuto-raises a low-confidence suspected-blockage report
Confidence & decay. A single unverified report starts at 0.45 confidence; each corroboration from a different reporter adds 0.2; an official advisory is 1.0. Confidence halves every 6 hours, so a segment re-opens on its own once nobody re-confirms the hazard — and any user can mark it Cleared, which drops confidence to 0.1 immediately.

What the algorithm does with each band

BandStatusEffect on routing
A ≥ 0.75OPENNormal travel cost. Segment fully available.
0.45–0.74CAUTIONSoft penalty — travel time divided by A, so the reward term (1 / Travel Cost) drops and the path is only chosen when its coverage and fairness gains justify it.
0.20–0.44RESTRICTEDRemoved from the default action set; usable only on explicit coordinator override, logged with a reason.
A < 0.20CLOSEDHard mask. The edge is deleted from the valid action set for that decision epoch, so the ε-greedy policy cannot select it even by random exploration. A community reachable only through it is deferred with an H-priority boost.
Because the state includes A, the same coordinate under a landslide and the same coordinate on a dry day are different states to the agent. This is exactly the “structural amnesia” that location-only standard Q-learning cannot represent. See the Analysis tab → SOP 3 for the full comparison.
